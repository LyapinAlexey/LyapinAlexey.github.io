# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue or pull request. Email [alexey.lyapin.inbox@gmail.com](mailto:alexey.lyapin.inbox@gmail.com) with:

- a description of the potential issue and its impact;
- steps or a proof of concept to reproduce it, if available;
- any relevant affected URL, file, or browser details.

Please give the maintainer a reasonable opportunity to investigate before sharing the details publicly. Do not access, alter, or retain data that is not yours while investigating.

## Scope

This repository contains a static portfolio website. The website does not provide an account system, backend API, or data submission form. Reports should identify a security impact in this repository or its published site; issues in third-party services should be reported to their respective providers.

There is no formal service-level agreement or guaranteed response time. The maintainer will assess reports as time permits.
